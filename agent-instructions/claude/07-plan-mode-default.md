# Plan Mode Default

<important if="you are starting a non-trivial task, making architectural decisions, recovering from a failed approach, or planning verification">
- Enter plan mode for any non-trivial task: 3+ steps, broad file impact, unclear requirements, or architectural decisions.
- Write a detailed upfront spec before implementation: goals, constraints, affected areas, verification plan, and open questions.
- Use plan mode for verification work as well as building work when verification has multiple steps or meaningful risk.
- If the work goes sideways, stop immediately and re-plan instead of pushing through with ad hoc fixes.
</important>
