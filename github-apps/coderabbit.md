# CodeRabbit

PR 自动出概览摘要 + 逐文件 review，增量 commit 增量 review；评论里 `@coderabbitai` 可触发 review、生成测试、解释代码。

App 安装：<https://github.com/apps/coderabbitai> · 配置见 [Configuration Reference](https://docs.coderabbit.ai/reference/configuration)

## 配置

仓库根放 `.coderabbit.yaml`（或 `.yml`）控制 review 行为：语言、语气、路径过滤、walk-through、自定义 check、knowledge base 等。
